MedQB v1.8 更新内容

回答後の選択肢解説を「正誤判定中心」から「選択肢そのものの知識解説中心」へ変更しました。

各選択肢について、
- これは何の分類か
- この選択肢は何なのか
- どんな疾患・場面・病態に関係するのか
- 一緒に覚えるキーワード
を先に詳しく表示します。

「他が優先」「この問題には関係ない」といった説明は中心にせず、
最後に「この設問との関係」として短く補足するだけにしました。

例：
ワルファリン
→ 抗凝固薬
→ ビタミンK依存性凝固因子II・VII・IX・Xを抑制
→ 心房細動、VTE、機械弁などに使用
→ PT-INRで管理
→ 妊娠中は原則避ける

v1.7の◎○△×自己評価、自動復習、習熟度などは継続します。
