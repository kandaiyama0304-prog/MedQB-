MedQB v1.4 更新内容

今回の重点
1. 画像問題の「解答後学習」を強化
   - 解答前は所見注釈を隠し、解答後に「所見を表示」ボタンを表示
   - 肺炎、心電図、高K血症、消化管穿孔、脳出血、眼底、帯状疱疹、
     TTP、APL、潰瘍性大腸炎、水腎症で注目部位をオーバーレイ表示
   - 画像をタップして拡大する機能は継続
   - 画像は教育用再現画像であることを明示

2. 問題文の体裁を統一
   - 症例問題を「患者」「現病歴・身体所見」「バイタル・検査所見」に整理
   - バイタル・検査値をチップ表示
   - 症例以外の問題にも「設問」カードを付与
   - 設問ボックスの視認性を改善

3. 解説を強化
   - 「この問題の判断の軸」を追加
   - 「正解の根拠」と「選択肢別解説」を分離
   - 各選択肢に ○正答 / ×誤答 を表示
   - 主要な臨床鑑別について、誤答選択肢の具体的な典型所見を追加
   - 一般問題でも診断・治療・検査・計算ごとに解説ロジックを改善

4. 学習メモ
   - 間違えた理由（知識不足、読み違い、画像所見の見落とし等）を
     残しやすい入力案内に変更
